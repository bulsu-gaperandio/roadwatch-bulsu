How RoadWatch Operates

A verified, transparent workflow bridging citizen reports and municipal road maintenance.

1️⃣

Citizen Submits Report

Motorists or students take a photo of the road damage, designate exact GPS coordinates on the interactive map, and submit it for inspection.

Status: Pending Review
2️⃣

Administrator Verification

Human highway evaluators inspect high-resolution photographs to determine if the road damage constitutes a legitimate pothole hazard.

Manual Human Review
3️⃣

Live Map Publication

Once approved, the pothole instantly appears on the public Google Map. Clicking the marker displays the original photograph and road information.

Status: Approved Pin

Check the pinned coordinates along Malolos / Bulacan roadways to prevent misidentified road stretches.

3. Approve or Reject:

Approved reports appear immediately on the public map. Rejected reports are excluded permanently from the confirmed map.

⚙️ Google Maps JavaScript API Setup

The system currently operates with a High-Fidelity Interactive Fallback Map (CartoDB Dark Matter / Leaflet) styled in our Space-Inspired theme, enabling full panning, zooming, marker placement, coordinate picking, and photo inspection without an external API key.

How to Activate Official Google Maps JS API

  1. Obtain a valid API key from the Google Cloud Console with Maps JavaScript API enabled.
  2. Paste your key below and click Apply Google Maps Key, or append ?maps_key=YOUR_KEY to the URL.
  3. If no key is supplied, the application continues to run seamlessly on the dark interactive fallback.
Do not commit private production server secrets. Browser keys should be origin-restricted.
